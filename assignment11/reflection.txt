Task 4 Reflection: Advanced Data Visualization

1. Differences between static and interactive visualizations:
Static visualizations (like Matplotlib charts) are ideal for fixed reports, print, and quick snapshots. Interactive visualizations (like Plotly) allow users to hover for details, zoom into specific data points, pan, and filter layers dynamically.

2. Advantages of dashboards for real-time data exploration:
Dashboards consolidate multiple data views into a unified interface, giving stakeholders live insights, interactive filtering capabilities, and immediate visibility into trends without requiring continuous code execution.

3. Improving data communication in professional settings:
Interactive tools like Plotly make technical data accessible to non-technical business partners. Users can explore specific data segments on demand, leading to faster data-driven decision-making.
